# 🌡️ 서울 기온이 의류소비에 미치는 영향 분석 (2019~2024)

> **분석 목적**: 서울 월평균기온이 의류 소매판매지수 및 계절 의류 검색 트렌드와 어떤 관계가 있는지 분석
> **분석 기간**: 2019년 1월 ~ 2024년 12월 (72개월)
> **사용 데이터**: 기상청 서울 월평균기온 / KOSIS 의복 소매판매지수 / 네이버 데이터랩 검색량(겨울옷·여름옷·봄옷)

## ⚙️ 실행 방법

### 1) 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 2) 노트북 실행

```bash
jupyter notebook analysis.ipynb
```

셀을 순서대로(위→아래) 실행하면 STEP 1~4 데이터 로딩·통합, 이동평균/증감률 계산, 시각화 3종, 상관분석까지 재현된다. 실행 결과 이미지는 `charts/` 폴더에 저장된다.

### 한글 폰트 설정

- Windows: `plt.rcParams['font.family'] = 'Malgun Gothic'`
- Mac: `plt.rcParams['font.family'] = 'AppleGothic'`
- Linux: 배포판에 설치된 한글 글꼴(예: `Noto Sans CJK JP`)로 대체

노트북 상단 설정 셀의 폰트명을 본인 운영체제에 맞게 바꿔서 실행하면 된다.

## 📊 분석 요약

- 사용 기법: 3개월 이동평균, 전월 대비 증감률, Pearson 상관분석(r, p-value)
- 당월 기온과 의류판매지수의 상관은 약함(r=-0.14, 유의하지 않음)이지만, '겨울옷' 검색량과의 상관은 뚜렷하고 유의함(r=0.44, p<0.001)
- 의류판매지수는 매년 가을(9~11월)에 정점, 여름(6~8월)에 저점을 반복
- 2020년은 전년 대비 전 월에 걸쳐 판매지수가 하락(코로나19 영향 추정)

자세한 분석 질문, 인사이트(관찰-해석-행동), 한계점, AI 사용 로그는 **`REPORT.md`**를 참고.
